# Worst AI Advice: The 48-Hour Tight Line

One line of the worst possible advice an AI could give, delivered in a deadpan assistant voice: a concrete, destructive action presented as a helpful recommendation. The joke is the advice itself — no commentary, no wink, just a confident assistant telling you to nuke production before your demo.

## How to run

```sh
python3 main.py
```

This writes a single line (at most 140 characters, no trailing newline) to `/output/entry.txt`. Deterministic — the same bytes on every run. Python standard library only, no network.
